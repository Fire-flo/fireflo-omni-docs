One contact, with every number and identifier they have, their fields, tags and consent.

<Note>Needs the `contacts:read` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `contact_id` | string | Yes | The contact's id. |

## Request

<CodeGroup>

```bash cURL
curl https://api.fireflo.au/v1/contacts/3f6b2a1e-8c4d-4e2a-9b7f-5d1c0e8a9f42 \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/contacts/3f6b2a1e-8c4d-4e2a-9b7f-5d1c0e8a9f42",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/contacts/3f6b2a1e-8c4d-4e2a-9b7f-5d1c0e8a9f42", {

    Authorization: `Bearer ${process.env.OMNI_API_KEY}`,
```

### The contact

| Field | Notes |
| :--- | :--- |
| `id` | The contact's id. |
| `phone` | Their main number, in international format. |
| `identifiers` | Every way they are known: their main number first (`primary`: true), then older numbers and other identifiers. `kind` is `phone`, `email`, `external_id`, `whatsapp_id`, `rcs_id` or `anonymous_id`. |
| `fields` | Their values for your account's contact fields, by field key. |
| `tags` | Tag names, sorted. |
| `consent` | `do_not_contact` (nothing is sent to them on any channel while true), its `reason` and `until` (null for good), and `opted_out_at` (when they opted out of marketing, or null). |
| `timezone`, `quiet_hours` | Their time zone, and the hours not to message them (`{start, end}`, or null). |
| `created`, `updated` | When the contact was added and last changed. |

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No contact has that id on this account. |
| 403 | `scope_missing` | The key doesn't have the `contacts:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
