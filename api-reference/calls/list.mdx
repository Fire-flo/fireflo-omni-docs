---
title: "GET /v1/calls"
description: "Your calls, newest first, whichever way they went."
---

Your calls on Voice, newest first, whichever way they went. An account without Voice gets an empty list.

<Note>Needs the `calls:read` scope.</Note>

## Query parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `direction` | string | No | `inbound` or `outbound`. |
| `status` | string | No | `dialling`, `started`, `ended`, `failed` or `missed`. |
| `kind` | string | No | `ivr`, `ai`, `inbound`, `phone`, `click` or `broadcast`. |
| `contact` | string | No | A contact's id: only their calls. |
| `limit` | integer | No | How many to answer with, 1 to 100. Default 50. |
| `starting_after` | string | No | The `next` of the previous page, to read the page after it. |

Lists are paged: `has_more` says whether there is more, and `next` is what to pass as `starting_after` to read it (null on the last page).

## Request

<CodeGroup>

```bash cURL
curl "https://api.fireflo.au/v1/calls?direction=outbound&limit=20" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/calls",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
    params={
        "direction": "outbound",
        "limit": 20,
    },
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/calls?direction=outbound&limit=20", {
  headers: {
    Authorization: `Bearer ${process.env.OMNI_API_KEY}`,
  },
});
console.log(response.status, await response.json());
```

</CodeGroup>

### The call

| Field | Notes |
| :--- | :--- |
| `id` | The call's id. |
| `kind` | `ivr` (rung into an IVR), `ai` (a voice agent), `inbound`, `phone` (dialled from a desk or app phone), `click` (click-to-call) or `broadcast`. |
| `direction` | `inbound` or `outbound`. |
| `to`, `number` | The number rung, and the other party's number. |
| `caller_id`, `did` | The number an outgoing call showed, and the number an incoming call rang. |
| `contact` | `{uuid, name}`, or null. |
| `ivr`, `agent`, `placed_by` | The IVR it went into, the agent who took it, and the team member who placed it. |
| `status` | `dialling`, `started` (in progress), `ended`, `failed` (not answered) or `missed` (rang in, nobody took it). |
| `reason` | Why it failed. |
| `seconds`, `recorded`, `summary` | How long it lasted, whether it was recorded, and a voice agent's summary. |
| `created`, `started_at`, `answered_at`, `ended_at` | When each happened, or null. |

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 400 | `invalid_request` | `direction` or `status` isn't one of its values (`field` names it). |
| 400 | `invalid_request` | `limit` isn't 1 to 100, or `starting_after` isn't an id from this list (`field` names it). |
| 403 | `scope_missing` | The key doesn't have the `calls:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
