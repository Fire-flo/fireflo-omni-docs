---
title: "GET /v1/events"
description: "Every event a webhook endpoint can subscribe to, with what each means."
---

Every event a webhook endpoint can ask for, in alphabetical order, with a sentence on what each means. Use these names in a webhook endpoint's `events`.

<Note>Needs the `webhooks:read` scope.</Note>

## Request

<CodeGroup>

```bash cURL
curl https://api.fireflo.au/v1/events \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/events",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/events", {
  headers: {
    Authorization: `Bearer ${process.env.OMNI_API_KEY}`,
  },
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 403 | `scope_missing` | The key doesn't have the `webhooks:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
