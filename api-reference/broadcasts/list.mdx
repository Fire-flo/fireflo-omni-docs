description: "The account's broadcasts, newest first — sent from the panel or the API."

The account's broadcasts, newest first, whether started in the panel or through the API.

<Note>Needs the `broadcasts:read` scope.</Note>

## Query parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `status` | string | No | `preparing`, `queued`, `scheduled`, `sending`, `paused`, `sent`, `failed` or `canceled`. |
| `channel` | string | No | Only this channel's. |
| `limit` | integer | No | 1 to 100; 50 by default. |
| `starting_after` | string | No | The last id of the previous page — `next` from it. |

## Request

<CodeGroup>

```bash cURL
curl "https://api.fireflo.au/v1/broadcasts?status=sending&limit=10" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/broadcasts?status=sending&limit=10",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/broadcasts?status=sending&limit=10", {
  headers: { Authorization: `Bearer ${process.env.OMNI_API_KEY}` },
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 400 | `invalid_request` | `status` or `limit` isn't one (`field` names it), or `starting_after` isn't an id from this list. |
| 403 | `scope_missing` | The key doesn't have the `broadcasts:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
