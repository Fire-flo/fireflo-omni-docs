---
title: "PATCH /v1/cdp/audiences/{audience_id}"
description: "Rename an audience, or change its rules — who is in it is then worked out again."
---

Renames an audience, changes its description, or changes its rules. Send only what changes. New rules make it `building` while who is in it is worked out again; people who no longer match leave it.

<Note>Needs the `cdp.audiences:write` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `audience_id` | string | Yes | The audience's id. |

## Body

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `name` | string | No | Up to 120 characters, and not another audience's name. |
| `description` | string | No | Up to 300 characters. |
| `rules` | object | No | The new rules, whole — as [POST /v1/cdp/audiences](/api-reference/customer-data/create-audience#rules) describes. |

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No audience of this account's has that id. |
| 400 | `invalid_request` | `field` names `name` (empty, or another audience has it) or `rules` (the message says what's wrong). |
| 403 | `scope_missing` | The key doesn't have the `cdp.audiences:write` scope. |
| 404 | `module_off` | The account doesn't have Customer data on. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
