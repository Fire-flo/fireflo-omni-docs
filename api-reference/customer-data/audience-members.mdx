---
title: "GET /v1/cdp/audiences/{audience_id}/members"
description: "Who is in an audience, latest to join first."
---

The people in an audience, latest to join first, with when each joined.

<Note>Needs the `cdp.audiences:read` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `audience_id` | string | Yes | The audience's id. |

## Query parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `limit` | integer | No | 1 to 100; 50 by default. |
| `starting_after` | string | No | The last contact id of the previous page — `next` from it. |

## Request

<CodeGroup>

```bash cURL
curl "https://api.fireflo.au/v1/cdp/audiences/5b2e8d14-7c3a-4f9e-a1d6-3e8b0c4f2a71/members?limit=2" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/cdp/audiences/5b2e8d14-7c3a-4f9e-a1d6-3e8b0c4f2a71/members?limit=2",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```


## Response

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No audience of this account's has that id. |
| 400 | `invalid_request` | `limit` isn't 1 to 100, or `starting_after` isn't an id from this list (`field` names it). |
| 403 | `scope_missing` | The key doesn't have the `cdp.audiences:read` scope. |
| 404 | `module_off` | The account doesn't have Customer data on. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
