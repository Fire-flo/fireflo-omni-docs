---
title: "DELETE /v1/cdp/audiences/{audience_id}"
description: "Delete an audience that no AI agent or other audience uses."
---

Deletes an audience. It can't be deleted while an AI agent's workflow or another audience's rules use it; take it out of those first. Broadcasts already sent to it keep their history.

<Note>Needs the `cdp.audiences:write` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `audience_id` | string | Yes | The audience's id. |

## Request

<CodeGroup>

```bash cURL
curl -X DELETE "https://api.fireflo.au/v1/cdp/audiences/5b2e8d14-7c3a-4f9e-a1d6-3e8b0c4f2a71" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.delete(
    "https://api.fireflo.au/v1/cdp/audiences/5b2e8d14-7c3a-4f9e-a1d6-3e8b0c4f2a71",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code)
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/cdp/audiences/5b2e8d14-7c3a-4f9e-a1d6-3e8b0c4f2a71", {
```

</CodeGroup>

## Response

`204 No Content` — no body.

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No audience of this account's has that id. |
| 409 | `in_use` | An AI agent or another audience uses it; the message names them. |
| 403 | `scope_missing` | The key doesn't have the `cdp.audiences:write` scope. |
| 404 | `module_off` | The account doesn't have Customer data on. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
