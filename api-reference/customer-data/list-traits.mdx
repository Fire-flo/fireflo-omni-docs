---
title: "GET /v1/cdp/traits"
description: "The built-in traits, and the account's own worked out from events."
---

Traits are facts worked out for every contact. This lists the built-in ones — worked out from messages, visits and deals — and the account's own, each worked out from an event over a window of days.

<Note>Needs the `cdp.contacts:read` scope.</Note>

## Request

<CodeGroup>

```bash cURL
curl "https://api.fireflo.au/v1/cdp/traits" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/cdp/traits",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/cdp/traits", {
  headers: {
    Authorization: `Bearer ${process.env.OMNI_API_KEY}`,
  },
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Response

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 403 | `scope_missing` | The key doesn't have the `cdp.contacts:read` scope. |
| 404 | `module_off` | The account doesn't have Customer data on. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
