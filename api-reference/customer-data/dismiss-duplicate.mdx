---
title: "POST /v1/cdp/duplicates/{duplicate_id}/dismiss"
description: "Say two contacts aren't the same person, so the pair isn't suggested again."
---

Says the two contacts in a pair aren't the same person. The pair leaves the list and isn't suggested again.

<Note>Needs the `cdp.contacts:write` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `duplicate_id` | integer | Yes | The pair's `id`, from [GET /v1/cdp/duplicates](/api-reference/customer-data/list-duplicates). |

## Request

<CodeGroup>

```bash cURL
curl -X POST "https://api.fireflo.au/v1/cdp/duplicates/4821/dismiss" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.post(
    "https://api.fireflo.au/v1/cdp/duplicates/4821/dismiss",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code)
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/cdp/duplicates/4821/dismiss", {
  method: "POST",
```

</CodeGroup>

## Response

`204 No Content` — no body.

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | The account has no open pair with that id — or it was already dismissed. |
| 403 | `scope_missing` | The key doesn't have the `cdp.contacts:write` scope. |
| 404 | `module_off` | The account doesn't have Customer data on. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
