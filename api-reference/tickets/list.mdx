title: "GET /v1/tickets"
description: "The account's tickets, newest first, filtered by status, priority, assignee, category or contact."
---

The account's tickets, newest first — opened by customers writing in, by the team, by AI agents or through the API.

<Note>Needs the `tickets:read` scope.</Note>

## Query parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `status` | string | No | `open`, `pending`, `solved` or `closed`. |
| `priority` | string | No | `normal`, `high` or `urgent`. |
| `assignee` | string | No | A team member's email: only theirs. Empty for tickets nobody is assigned. |
| `category` | integer | No | A category's id: only its tickets. |
| `contact` | string | No | A contact's id: only their tickets. |
| `limit` | integer | No | 1 to 100; 50 by default. |
| `starting_after` | string | No | The last id of the previous page — `next` from it. |

## Request

<CodeGroup>

```bash cURL
curl "https://api.fireflo.au/v1/tickets?status=open&assignee=priya@acme.in&limit=20" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/tickets?status=open&assignee=priya@acme.in&limit=20",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/tickets?status=open&assignee=priya@acme.in&limit=20", {
  headers: { Authorization: `Bearer ${process.env.OMNI_API_KEY}` },
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 400 | `invalid_request` | `status` or `limit` isn't one, no one in your team has the `assignee` email, no contact has the `contact` id, or `starting_after` isn't an id from this list (`field` names it). |
| 404 | `module_off` | The account's plan doesn't include Tickets. |
| 403 | `scope_missing` | The key doesn't have the `tickets:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
