---
title: "GET /v1/routes/{route_id}"
description: "One route and its steps."
---

One route: its name, its steps and whether it is the default.

<Note>Needs the `routes:read` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `route_id` | string | Yes | The route's id. |

## Request

<CodeGroup>

```bash cURL
curl https://api.fireflo.au/v1/routes/b1d6e0a4-2f3c-4a5b-8e9d-7c6f5a4b3e21 \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/routes/b1d6e0a4-2f3c-4a5b-8e9d-7c6f5a4b3e21",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/routes/b1d6e0a4-2f3c-4a5b-8e9d-7c6f5a4b3e21", {
  headers: {
    Authorization: `Bearer ${process.env.OMNI_API_KEY}`,
  },
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Response

`200 OK`

```json
{
  "id": "b1d6e0a4-2f3c-4a5b-8e9d-7c6f5a4b3e21",
  "name": "whatsapp-then-sms",
  "steps": [
    {
      "channel": "whatsapp",
      "succeed_on": "read",
      "within": 600
    },
    {
      "channel": "sms",
      "succeed_on": "delivered",
      "within": 900
    }
  ],
  "default": true,
  "updated": "2026-10-02T11:40:05.217Z"
}
```

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No route has that id on this account. |
| 403 | `scope_missing` | The key doesn't have the `routes:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
