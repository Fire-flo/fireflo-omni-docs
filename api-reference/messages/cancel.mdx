---
title: "POST /v1/messages/{message_id}/cancel"
description: "Stop a message that is still being tried, so no further channel is tried."
---

Stops a message that is still `delivering` or `postponed`: no further channel is tried, and it ends `canceled` (a `message.canceled` event follows). A message already handed to a channel is not called back from it.

<Note>Needs the `messages:send` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `message_id` | string | Yes | The message's id, `msg_…`. |

## Request

<CodeGroup>

```bash cURL
curl -X POST https://api.fireflo.au/v1/messages/msg_8f14e45fceea167a5a36dedd4bea2543/cancel \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.post(
    "https://api.fireflo.au/v1/messages/msg_8f14e45fceea167a5a36dedd4bea2543/cancel",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```


## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No message has that id on this account. |
| 409 | `already_finished` | The message has already succeeded, failed, expired or been canceled. |
| 403 | `scope_missing` | The key doesn't have the `messages:send` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
