---
title: "GET /v1/messages"
description: "The messages sent through the API, newest first."
---

The latest messages, newest first — 50 unless `limit` says — each with every attempt on every channel. Narrow it with `reference`, `status` or `q`.

<Note>Needs the `messages:read` scope.</Note>

## Query parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `reference` | string | No | Only messages sent with this `reference`. |
| `status` | string | No | `delivering`, `postponed`, `succeeded`, `failed`, `expired` or `canceled`. |
| `q` | string | No | Messages whose reference, number or contact's name contains this. |
| `limit` | integer | No | How many, from 1 to 100. 50 when left out. |

## Request

<CodeGroup>

```bash cURL
curl "https://api.fireflo.au/v1/messages?reference=order-A-1042" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/messages",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
    params={
        "reference": "order-A-1042",
    },
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/messages?reference=order-A-1042", {
  headers: {
    Authorization: `Bearer ${process.env.OMNI_API_KEY}`,
  },
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 403 | `scope_missing` | The key doesn't have the `messages:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
