---
title: "DELETE /v1/catalogue/sets/{set_id}"
description: "Delete a product set — its products stay in the catalogue."
---

Deletes a set. Its products aren't touched: they stay in the catalogue and in any other set.

<Note>Needs the `catalogue.products:write` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `set_id` | string | Yes | The set's id. |

## Request

<CodeGroup>

```bash cURL
curl -X DELETE "https://api.fireflo.au/v1/catalogue/sets/c4e81f2a-6b7d-4a39-8e15-0d3f9b2a7c61" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.delete(
    "https://api.fireflo.au/v1/catalogue/sets/c4e81f2a-6b7d-4a39-8e15-0d3f9b2a7c61",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code)
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/catalogue/sets/c4e81f2a-6b7d-4a39-8e15-0d3f9b2a7c61", {
  method: "DELETE",
  headers: { Authorization: `Bearer ${process.env.OMNI_API_KEY}` },
});
console.log(response.status);
```

</CodeGroup>

## Response

`204 No Content` — no body.

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No set of this account's has that id. |
| 404 | `module_off` | The account doesn't have Catalogue on. |
| 403 | `scope_missing` | The key doesn't have the `catalogue.products:write` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
