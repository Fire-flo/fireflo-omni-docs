---
title: "POST /v1/catalogue/sets"
description: "Add an empty product set to the catalogue."
---

Adds a product set, empty. Put products in it with their `sets` — on [POST](/api-reference/catalogue/add-product) or [PATCH /v1/catalogue/products/\{product_id\}](/api-reference/catalogue/update-product), or the `sets` column of an [import](/api-reference/catalogue/import-products).

<Note>Needs the `catalogue.products:write` scope.</Note>

## Body

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `name` | string | Yes | Up to 80 characters, not used by another of the account's sets. |
| `description` | string | No | Up to 200 characters. |

## Request

<CodeGroup>

```bash cURL
curl -X POST "https://api.fireflo.au/v1/catalogue/sets" \
  -H "Authorization: Bearer $OMNI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "name": "Diwali edit",
  "description": "Festive picks, sent as one product list."
}'
```

```python Python
import os

import requests

response = requests.post(
    "https://api.fireflo.au/v1/catalogue/sets",
    headers={
        "Authorization": f"Bearer {os.environ['OMNI_API_KEY']}",
    },
    json={
        "name": "Diwali edit",
        "description": "Festive picks, sent as one product list.",
    },
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/catalogue/sets", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.OMNI_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    "name": "Diwali edit",
    "description": "Festive picks, sent as one product list."
  }),
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Response

`201 Created` — the set.

```json
{
  "id": "c4e81f2a-6b7d-4a39-8e15-0d3f9b2a7c61",
  "name": "Diwali edit",
  "description": "Festive picks, sent as one product list.",
  "products": 0
}
```

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 400 | `invalid_request` | `name` is missing, empty, too long or already a set's, or `description` is too long (`field` names it). |
| 404 | `module_off` | The account doesn't have Catalogue on. |
| 403 | `scope_missing` | The key doesn't have the `catalogue.products:write` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
