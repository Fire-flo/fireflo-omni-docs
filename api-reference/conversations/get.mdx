---
title: "GET /v1/conversations/{contact_id}"
description: "One conversation, with which channels can take a typed reply now."
---

One conversation, and where a reply can go. `reply.channels` says, for each of its channels, whether it can take typed text now and until when — a WhatsApp conversation is open for 24 hours after the person last wrote — and `reply.channel` is where a reply goes if you name none: the channel they last wrote on, or failing that the first one open.

<Note>Needs the `conversations:read` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `contact_id` | string | Yes | The person's contact id: it names their conversation. |

## Request

<CodeGroup>

```bash cURL
curl https://api.fireflo.au/v1/conversations/3f6b2a1e-8c4d-4e2a-9b7f-5d1c0e8a9f42 \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

### The conversation

| Field | Notes |
| :--- | :--- |
| `id` | The person's contact id: a conversation is one thread per person, across every channel. |
| `contact` | `{id, name, phone}`. |
| `channels` | The channels they have written or been written to on. |
| `state` | `open`, `snoozed` or `closed`; `snoozed_until` while snoozed. |
| `assignee` | `{name, email}` of the team member it is assigned to, or null. |
| `priority` | `normal`, `high` or `urgent`. |
| `labels` | Label names, sorted. |
| `unread` | How many of their messages haven't been read. |
| `waiting_since` | Since when they have been waiting for an answer, or null. |
| `last_message_at`, `created` | The latest message, and when the thread began. |

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No conversation has that id on this account. |
| 403 | `scope_missing` | The key doesn't have the `conversations:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
