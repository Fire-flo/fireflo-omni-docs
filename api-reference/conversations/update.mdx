---
title: "PATCH /v1/conversations/{contact_id}"
description: "Close or reopen a conversation, snooze it, assign it, set its priority or labels."
---

Changes a conversation as a team member would in the Inbox, leaving the same trail. Only what the body gives changes. Assigning it to a person makes an AI agent on the thread step back.

<Note>Needs the `conversations:write` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `contact_id` | string | Yes | The person's contact id: it names their conversation. |

## Body

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `state` | string | No | `open` or `closed`. |
| `assignee` | string | No | A team member's email, or null for nobody. |
| `priority` | string | No | `normal`, `high` or `urgent`. |
| `snoozed_until` | string | No | An ISO time with its offset, in the future; null wakes it. |
| `labels` | array | No | Label names that exist on the account. Replaces its labels. |

## Request

<CodeGroup>

```bash cURL
curl -X PATCH https://api.fireflo.au/v1/conversations/3f6b2a1e-8c4d-4e2a-9b7f-5d1c0e8a9f42 \
  -H "Authorization: Bearer $OMNI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "assignee": "priya@acme.in",
    "priority": "high",
    "labels": [
      "orders"
    ]
  }'
```

```python Python
import os

import requests

response = requests.patch(
    "https://api.fireflo.au/v1/conversations/3f6b2a1e-8c4d-4e2a-9b7f-5d1c0e8a9f42",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
    json={
        "assignee": "priya@acme.in",
        "priority": "high",
        "labels": ["orders"],
    },
)
print(response.status_code, response.json())
```

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No conversation has that id on this account. |
| 400 | `invalid_request` | An input is wrong: an unknown state or priority, no active team member with that email, a snooze time that is bad or past, an unknown label (`field` names it). |
| 400 | `invalid_json` | The body isn't valid JSON. |
| 403 | `scope_missing` | The key doesn't have the `conversations:write` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
