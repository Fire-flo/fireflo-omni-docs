Your message templates: one message written once per channel, and the values each needs.

<Note>Needs the `templates:read` scope.</Note>

## Request

<CodeGroup>

```bash cURL
curl https://api.fireflo.au/v1/templates \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/templates",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/templates", {
  headers: {
    Authorization: `Bearer ${process.env.OMNI_API_KEY}`,
  },
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Response

`200 OK`

```json
{
  "data": [
    {
      "id": "7a2c9e14-5b3d-4f6a-8c1e-2d9b0f7e6a53",
      "name": "order_shipped",
      "description": "Sent when the warehouse ships an order",
      "variants": {
        "whatsapp": {
          "text": "Hi {{name}}, your order {{order}} has shipped.",
          "template": "order_shipped",
          "language": "en",
          "params": [
            "{{name}}",
            "{{order}}"
          ]
        },
        "sms": {
          "text": "Hi {{name}}, your order {{order}} has shipped. - Acme"
        }
      },
      "variables": [
        "name",
        "order"
      ],
      "updated": "2026-10-01T06:12:44.580Z",
      "recent_sends": 128
    }
  ],
  "channels": [
    {
      "key": "whatsapp",
      "label": "WhatsApp",
      "goals": ["sent", "delivered", "read"],
      "fields": [
        { "field": "text", "label": "Text", "kind": "text" },
        { "field": "template", "label": "Template", "kind": "line" }
      ]
    },
    {
      "key": "sms",
      "label": "SMS",
      "goals": ["sent", "delivered"],
      "fields": [{ "field": "text", "label": "Text", "kind": "text" }]
    }
  ]
}
```

`recent_sends` is how many messages used the template in the last 30 days. `channels`
lists the channels a variant may be written for, and the fields each takes (abbreviated
above).

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 403 | `scope_missing` | The key doesn't have the `templates:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
