## Scopes

A key may only do what its scopes allow; anything else is refused with `scope_missing`.
`GET /v1/me` needs none.

| Scope | Lets a key |
| :--- | :--- |
| `account:read` | See which account and plan the key belongs to |
| `messages:send` | Send messages, with failover between channels, and cancel them |
| `messages:read` | Read messages and their attempts |
| `routes:read` | See routes |
| `routes:write` | Add, change and remove routes |
| `templates:read` | See message templates |
| `templates:write` | Add, change and remove message templates |
| `contacts:read` | Look up and list contacts |
| `contacts:write` | Add and change contacts, their tags and their consent |
| `conversations:read` | Read Inbox conversations and their messages |
| `conversations:write` | Reply in conversations, and close, assign or label them |
| `senders:read` | See the sender IDs, numbers and bots messages can come from |
| `calls:read` | See calls, what was said on them, and what a call can go into |
| `calls:write` | Ring people into an IVR or have a voice agent call them |
| `usage:read` | See what was sent, received and called, and what it cost |
| `broadcasts:read` | See broadcasts, how they are going and the messages they sent |
| `broadcasts:write` | Start broadcasts, and pause, resume, cancel or send them now |
| `webhooks:read` | See webhook endpoints and what was sent to them |
| `webhooks:write` | Add, change and remove webhook endpoints |

### Analytics

Present when the account has [Analytics](/analytics/reports).

| Scope | Lets a key |
| :--- | :--- |
| `reports:read` | Run Analytics reports and fetch the files scheduled reports write |

### A channel's own

Present when the account has the channel.

| Scope | Lets a key |
| :--- | :--- |
| `whatsapp.templates:read` | See WhatsApp message templates and their approval |
| `whatsapp.templates:write` | Submit, edit and delete WhatsApp message templates |
| `sms.senders:read` | See SMS sender ID registrations |
| `sms.senders:write` | Request and withdraw SMS sender IDs |
| `sms.templates:read` | See SMS DLT template registrations |
| `sms.templates:write` | Request and withdraw SMS DLT templates |
| `sms.balance:read` | See the SMS gateway's balance |

### A battery's own

Present when the account has the battery. Each battery's guide says what its endpoints do:
[Pipelines](/developers/pipelines), [Tickets](/developers/tickets),
[Calendar](/developers/calendar), [Catalogue](/developers/catalogue),
[Customer data](/developers/customer-data) and [AI agents](/developers/ai-agents).

| Scope | Lets a key |
| :--- | :--- |
| `crm.pipelines:read` | See pipelines and their stages |
| `crm.pipelines:write` | Add, rename, reorder and remove pipelines and stages |
| `crm.deals:read` | See deals, their notes and their history |
| `crm.deals:write` | Create, move, change and delete deals, and add notes |
| `tickets:read` | See tickets, their notes and history, and categories |
| `tickets:write` | Open, change, solve and close tickets, add notes, manage categories |
| `calendar:read` | See booking types, the team, free times and appointments |
| `calendar:write` | Book, move, confirm and cancel appointments, and set up booking types |
| `catalogue.products:read` | See products and sets |
| `catalogue.products:write` | Add, change, import and take products off sale; manage sets |
| `catalogue.orders:read` | See orders |
| `catalogue.orders:write` | Place orders, and confirm, decline, fulfil or cancel them |
| `cdp.events:write` | Send events: identify, track and batch |
| `cdp.audiences:read` | See audiences and who is in them |
| `cdp.audiences:write` | Create, change, refresh and delete audiences |
| `cdp.contacts:read` | See traits, consent and suggested duplicates |
| `cdp.contacts:write` | Add and remove traits, record consent, merge contacts |
| `agents:read` | See agents, their workflows, who they work, plans, activity and usage |
| `agents:write` | Create, set up, publish, switch on and off, and delete agents |
| `agents.knowledge:read` | See what agents know |
| `agents.knowledge:write` | Add, change, re-read and remove knowledge |
| `agents.contacts:write` | Put agents on contacts, pause, resume, run and release them |
| `agents.plans:write` | Approve, reject and cancel agents' plans |

## Webhook events

How they are delivered, signed and retried: [Webhooks](/developers/webhooks).
`GET /v1/events` lists them too.

| Event | `data` carries | When |
| :--- | :--- | :--- |
| `message.attempted` | `message` | A message was handed to a channel |
| `message.failed_over` | `message` | A channel didn't get it there; the next one is trying |
| `message.succeeded` | `message` | A message reached the person as its route asked |
| `message.failed` | `message` | Every channel was tried, or the person may not be reached |
| `message.expired` | `message` | A message ran out of time before it got there |
| `message.canceled` | `message` | A message was canceled before it got there |
| `channel_message.received` | `channel_message` | Someone sent a message, on any channel |
| `channel_message.sent` | `channel_message` | A channel message was handed to the channel |
| `channel_message.delivered` | `channel_message` | A channel message reached the phone |
| `channel_message.read` | `channel_message` | A channel message was read |
| `channel_message.failed` | `channel_message` | A channel message could not be delivered |
| `call.started` | `call` | A call started, either way |
| `call.answered` | `call` | A call was answered |
| `call.ended` | `call` | A call ended after being answered |
| `call.failed` | `call` | A call you placed wasn't answered |
| `call.missed` | `call` | A call rang in and nobody took it |
| `broadcast.scheduled` | `broadcast` | A broadcast is ready and waiting for its time |
| `broadcast.sending` | `broadcast` | A broadcast started sending |
| `broadcast.paused` | `broadcast` | A broadcast was paused |
| `broadcast.resumed` | `broadcast` | A paused broadcast was resumed |
| `broadcast.sent` | `broadcast` | A broadcast finished: every message was handed to the channel |
| `broadcast.failed` | `broadcast` | A broadcast couldn't be sent |
| `broadcast.canceled` | `broadcast` | A broadcast was canceled |
| `report.delivered` | `report`, `schedule`, `period`, `columns`, `totals`, `rows`, `file` | A [scheduled report](/developers/reports#scheduled-reports-to-your-webhooks) was sent — with Analytics |
| `deal.created` | `deal`, `changed` | A deal was created — with Pipelines |
| `deal.updated` | `deal`, `changed` | A deal's title, value, contact or notes changed |
| `deal.stage_changed` | `deal`, `changed` | A deal moved to another stage |
| `deal.won` | `deal`, `changed` | A deal was won |
| `deal.lost` | `deal`, `changed` | A deal was lost |
| `deal.reopened` | `deal`, `changed` | A won or lost deal was opened again |
| `deal.deleted` | `deal` (its id and title) | A deal was deleted |
| `ticket.opened` | `ticket`, `change` | A ticket was opened — with Tickets |
| `ticket.updated` | `ticket`, `change` | A ticket's status, assignee, priority, category or subject changed |
| `ticket.solved` | `ticket`, `change` | A ticket was solved |
| `ticket.closed` | `ticket`, `change` | A ticket was closed — `change` is left out when it closed on its own, after the account's window |
| `ticket.reopened` | `ticket`, `change` | A solved ticket was opened again |
| `appointment.booked` | `appointment`, `change` | An appointment was booked — with Calendar |
| `appointment.rescheduled` | `appointment`, `change` | An appointment moved to another time |
| `appointment.updated` | `appointment`, `change` | An appointment's place, link or mode changed |
| `appointment.confirmed` | `appointment`, `change` | A requested appointment was confirmed |
| `appointment.completed` | `appointment`, `change` | An appointment was marked done |
| `appointment.canceled` | `appointment`, `change` | An appointment was canceled |
| `appointment.no_show` | `appointment`, `change` | The contact didn't come |
| `order.opened` | `order` | An order was placed — from a cart, an agent or the API — with Catalogue |
| `order.confirmed` | `order` | An order was confirmed |
| `order.declined` | `order` | An order was declined |
| `order.fulfilled` | `order` | An order was fulfilled |
| `order.canceled` | `order` | An order was canceled |
| `product.changed` | `product` | A product was added or changed (not by a CSV import) |
| `audience.entered` | `audience`, `contacts` | Contacts joined an audience — with Customer data; up to 500 contacts an event |
| `audience.left` | `audience`, `contacts` | Contacts left an audience |
| `consent.changed` | `contact`, `consent` | A contact's consent changed, on a channel or all |
| `contacts.merged` | `contact`, `merged` | Two contacts were merged into one |
| `agent.plan_proposed` | `agent`, `contact`, `plan`, `summary` | An agent's plan is waiting for someone to approve — with AI agents |
| `agent.assignment_changed` | `agent`, `contact`, `kind`, `summary` | An agent started, paused, resumed or stopped working a contact |
| `agent.handed_over` | `agent`, `contact`, `reason` | An agent handed a contact to the team |
| `webhook.test` | `endpoint` | A test, sent from the endpoint's screen or the API |
