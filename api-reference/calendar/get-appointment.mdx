title: "GET /v1/calendar/appointments/{appointment_id}"
description: "One appointment, with its history."
---

One appointment, with everything that has happened to it.

<Note>Needs the `calendar:read` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `appointment_id` | string | Yes | The appointment's id. |

## Request

<CodeGroup>

```bash cURL
curl "https://api.fireflo.au/v1/calendar/appointments/5b0e7d3c-9a2f-4c61-8e47-1f3a6c9d2b84" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/calendar/appointments/5b0e7d3c-9a2f-4c61-8e47-1f3a6c9d2b84",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/calendar/appointments/5b0e7d3c-9a2f-4c61-8e47-1f3a6c9d2b84", {
  headers: { Authorization: `Bearer ${process.env.OMNI_API_KEY}` },
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Response

`200 OK` — the appointment, and its `history`, oldest first: each `{kind, summary, at}`, where `kind` is `booked`, `rescheduled`, `edited`, `confirmed`, `completed`, `cancelled` or `no_show`.

| Field | Meaning |
| :--- | :--- |
| `id` | The appointment's id. |
| `title` | What it is — the booking type's name when it was booked. |
| `status` | `requested`, `confirmed`, `completed`, `cancelled` or `no_show`. |
| `booking_type` | `{id, name}`, or `null`. |
| `contact` | Who it is with: `{id, name, phone}`. |
| `staff` | The teammate who takes it, `{name, email}`. |
| `starts_at`, `ends_at` | When, in the account's timezone with its offset. |
| `mode` | `online` or `physical`. |
| `location`, `meeting_link` | Where it happens — the place in person, the link online. |
| `notes` | The team's notes. |
| `source` | Where it was booked: `panel`, `inbox`, `agent`, `workflow`, `link` (online booking) or `api`. |
| `deal` | The id of the deal it belongs to, with Pipelines, or `null`. |
| `created_at`, `updated_at` | When it was booked, and last changed. |

`status` is one of:

| Status | Meaning |
| :--- | :--- |
| `requested` | Booked, waiting to be confirmed. |
| `confirmed` | Booked and confirmed. |
| `completed` | It happened. |
| `cancelled` | It was canceled. |
| `no_show` | The contact didn't come. |

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No appointment of this account's has that id. |
| 404 | `module_off` | The account's plan doesn't include Calendar. |
| 403 | `scope_missing` | The key doesn't have the `calendar:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
