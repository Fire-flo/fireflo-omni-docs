---
title: "POST /v1/calendar/appointments/{appointment_id}/reschedule"
description: "Move an upcoming appointment to another free time, optionally with another teammate."
---

Moves an upcoming appointment — `requested` or `confirmed` — to another free time of its booking type, keeping its length and prep time. It stays with the same teammate unless `staff` names another. The contact is told and reminded as when the team moves it, and `appointment.rescheduled` is sent.

<Note>Needs the `calendar:write` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `appointment_id` | string | Yes | The appointment's id. |

## Body

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `starts_at` | string | Yes | The new start, with its offset: `2026-10-09T11:00:00+05:30`. A free start for the booking type. |
| `staff` | string | No | The email of a teammate who takes the booking type, to hand it to. |

Its own time doesn't count against it: moving it by a few minutes works.

## Request

<CodeGroup>

```bash cURL
curl -X POST "https://api.fireflo.au/v1/calendar/appointments/5b0e7d3c-9a2f-4c61-8e47-1f3a6c9d2b84/reschedule" \
  -H "Authorization: Bearer $OMNI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "starts_at": "2026-10-09T11:00:00+05:30"
}'
```

```python Python
import os

import requests

response = requests.post(
    "https://api.fireflo.au/v1/calendar/appointments/5b0e7d3c-9a2f-4c61-8e47-1f3a6c9d2b84/reschedule",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
    json={
        "starts_at": "2026-10-09T11:00:00+05:30"
    },
)
print(response.status_code, response.json())
```

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No appointment of this account's has that id. |
| 400 | `invalid_request` | `starts_at` is missing or has no offset, or `staff` isn't in your team or doesn't take this booking type (`field` names it). |
| 409 | `slot_taken` | That time isn't free — pick another from the free times. |
| 409 | `invalid_state` | Only an upcoming appointment can be moved: this one is completed, canceled or a no-show. |
| 404 | `module_off` | The account's plan doesn't include Calendar. |
| 403 | `scope_missing` | The key doesn't have the `calendar:write` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
