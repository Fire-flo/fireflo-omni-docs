---
title: "GET /v1/calendar/appointments"
description: "The account's appointments, newest first, by day, status, teammate or contact."
---

The account's appointments, the most recently booked first — booked in the panel, the Inbox, by an AI agent, a workflow, online booking or the API.

<Note>Needs the `calendar:read` scope.</Note>

## Query parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `from` | string | No | `YYYY-MM-DD`: only appointments ending on or after this day. |
| `to` | string | No | `YYYY-MM-DD`: only appointments starting on or before this day. |
| `status` | string | No | `requested`, `confirmed`, `completed`, `cancelled` or `no_show`. |
| `staff` | string | No | A teammate's email: only theirs. |
| `contact` | string | No | A contact's id: only theirs. |
| `limit` | integer | No | 1 to 100; 50 by default. |
| `starting_after` | string | No | The last id of the previous page — `next` from it. |

## Request

<CodeGroup>

```bash cURL
curl "https://api.fireflo.au/v1/calendar/appointments?from=2026-10-08&to=2026-10-14&limit=20" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/calendar/appointments?from=2026-10-08&to=2026-10-14&limit=20",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/calendar/appointments?from=2026-10-08&to=2026-10-14&limit=20", {
  headers: { Authorization: `Bearer ${process.env.OMNI_API_KEY}` },
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 400 | `invalid_request` | `status`, `staff`, `contact` or `limit` isn't one (`field` names it), or `starting_after` isn't an id from this list. |
| 404 | `module_off` | The account's plan doesn't include Calendar. |
| 403 | `scope_missing` | The key doesn't have the `calendar:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
