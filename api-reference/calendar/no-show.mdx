---
title: "POST /v1/calendar/appointments/{appointment_id}/no-show"
description: "Mark that the contact didn't come to an appointment."
---

Marks that the contact didn't come to an upcoming appointment — `requested` or `confirmed`. Reminders not yet sent are dropped. The change is added to the appointment's history, and `appointment.no_show` is sent.

<Note>Needs the `calendar:write` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `appointment_id` | string | Yes | The appointment's id. |

## Body

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `note` | string | No | What happened — added to the history. Up to 200 characters. |

## Request

<CodeGroup>

```bash cURL
curl -X POST "https://api.fireflo.au/v1/calendar/appointments/5b0e7d3c-9a2f-4c61-8e47-1f3a6c9d2b84/no-show" \
  -H "Authorization: Bearer $OMNI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "note": "No answer on two calls"
}'
```

```python Python
import os

import requests

response = requests.post(
    "https://api.fireflo.au/v1/calendar/appointments/5b0e7d3c-9a2f-4c61-8e47-1f3a6c9d2b84/no-show",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
    json={
        "note": "No answer on two calls"
    },
)
print(response.status_code, response.json())
```

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No appointment of this account's has that id. |
| 409 | `invalid_state` | Only an upcoming appointment can be marked a no-show: this one is completed, canceled or a no-show. |
| 404 | `module_off` | The account's plan doesn't include Calendar. |
| 403 | `scope_missing` | The key doesn't have the `calendar:write` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
