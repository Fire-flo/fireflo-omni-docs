---
title: "POST /v1/calendar/appointments/{appointment_id}/cancel"
description: "Cancel an upcoming appointment, with an optional note."
---

Cancels an upcoming appointment — `requested` or `confirmed`. Its time is free again, reminders not yet sent are dropped, and the contact and the teammate are told as when the team cancels it. The change is added to the appointment's history, and `appointment.canceled` is sent.

<Note>Needs the `calendar:write` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `appointment_id` | string | Yes | The appointment's id. |

## Body

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `note` | string | No | Why — added to the history. Up to 200 characters. |

## Request

<CodeGroup>

```bash cURL
curl -X POST "https://api.fireflo.au/v1/calendar/appointments/5b0e7d3c-9a2f-4c61-8e47-1f3a6c9d2b84/cancel" \
  -H "Authorization: Bearer $OMNI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "note": "Ravi will come back after Diwali"
}'
```

```python Python
import os

import requests

response = requests.post(
    "https://api.fireflo.au/v1/calendar/appointments/5b0e7d3c-9a2f-4c61-8e47-1f3a6c9d2b84/cancel",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
    json={
        "note": "Ravi will come back after Diwali"
    },
)
print(response.status_code, response.json())
```

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No appointment of this account's has that id. |
| 409 | `invalid_state` | Only an upcoming appointment can be canceled: this one is completed, canceled or a no-show. |
| 404 | `module_off` | The account's plan doesn't include Calendar. |
| 403 | `scope_missing` | The key doesn't have the `calendar:write` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
