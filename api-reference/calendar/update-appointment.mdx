---
title: "PATCH /v1/calendar/appointments/{appointment_id}"
description: "Change an appointment's notes, place, meeting link or mode."
---

Changes an appointment's details. Send only what changes. To move it to another time or teammate, [reschedule it](/api-reference/calendar/reschedule). A change other than to `notes` is added to its history and sends `appointment.updated`.

<Note>Needs the `calendar:write` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `appointment_id` | string | Yes | The appointment's id. |

## Body

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `notes` | string | No | The team's notes. Up to 5,000 characters. |
| `location` | string | No | Where it happens in person. Up to 255 characters. |
| `meeting_link` | string | No | The link for online. Up to 500 characters. |
| `mode` | string | No | `online` or `physical`. |

## Request

<CodeGroup>

```bash cURL
curl -X PATCH "https://api.fireflo.au/v1/calendar/appointments/5b0e7d3c-9a2f-4c61-8e47-1f3a6c9d2b84" \
  -H "Authorization: Bearer $OMNI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "mode": "physical",
  "location": "Kaveri Homes, 2nd floor, Kalpataru Plaza, Andheri East, Mumbai"
}'
```

```python Python
import os

import requests

response = requests.patch(
    "https://api.fireflo.au/v1/calendar/appointments/5b0e7d3c-9a2f-4c61-8e47-1f3a6c9d2b84",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
    json={
        "mode": "physical",
        "location": "Kaveri Homes, 2nd floor, Kalpataru Plaza, Andheri East, Mumbai"
    },
)
print(response.status_code, response.json())
```

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No appointment of this account's has that id. |
| 400 | `invalid_request` | A field isn't text, is too long, or `mode` isn't `online` or `physical` (`field` names it). |
| 404 | `module_off` | The account's plan doesn't include Calendar. |
| 403 | `scope_missing` | The key doesn't have the `calendar:write` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
