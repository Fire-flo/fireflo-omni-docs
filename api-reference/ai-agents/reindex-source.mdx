---
title: "POST /v1/agents/knowledge/sources/{source_id}/reindex"
description: "Read a knowledge source again now — a website's pages, a file or an article."
---

Reads a source again now, whether or not it changed — for a website whose pages were updated, say, or a source that `failed`.

<Note>Needs the `agents.knowledge:write` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `source_id` | string | Yes | The source's id. |

## Request

<CodeGroup>

```bash cURL
curl -X POST "https://api.fireflo.au/v1/agents/knowledge/sources/0c9a8b7d-6e5f-4a3b-8c2d-1e0f9a8b7c6d/reindex" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.post(
    "https://api.fireflo.au/v1/agents/knowledge/sources/0c9a8b7d-6e5f-4a3b-8c2d-1e0f9a8b7c6d/reindex",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/agents/knowledge/sources/0c9a8b7d-6e5f-4a3b-8c2d-1e0f9a8b7c6d/reindex", {
```

## Response

`200 OK` — the source, `processing` until it has been read. A source has its `id`, `kind` (`article`, `faq`, `file` or `website`), `title` (an FAQ's question), its `collection`, whether agents use it (`active`) and when it last changed. `status` is `processing` while it is read, then `ready` — or `failed`, with the reason in `error`. An article or FAQ has its `body`; a website its `url`, how often it is checked for changes (`refresh`) and how many `pages` it reads; a file its `file` type and size in bytes.

```json
{
  "id": "0c9a8b7d-6e5f-4a3b-8c2d-1e0f9a8b7c6d",
  "kind": "website",
  "title": "help.sharmaelectronics.in/returns",
  "collection": {
    "id": 3,
    "name": "Returns & warranty"
  },
  "status": "processing",
  "error": "",
  "active": true,
  "updated_at": "2026-10-06T09:48:33+05:30",
  "url": "https://help.sharmaelectronics.in/returns",
  "refresh": "weekly",
  "pages": 3
}
```

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No knowledge source of this account's has that id. |
| 404 | `module_off` | The account doesn't have AI agents on: they aren't in its plan, or are switched off for it. |
| 403 | `scope_missing` | The key doesn't have the `agents.knowledge:write` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
