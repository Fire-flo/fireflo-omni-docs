---
title: "GET /v1/agents/usage"
description: "The AI tokens agents used on your own keys, per day, agent, pipeline and model."
---

Where your agents' AI tokens went — the panel's **AI agents → Usage**. The tokens are used on your own AI keys and billed by your AI provider; OMNI doesn't charge for them.

<Note>Needs the `agents:read` scope.</Note>

## Query parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `days` | integer | No | `7`, `14` or `30`; 14 by default. |

## Request

<CodeGroup>

```bash cURL
curl "https://api.fireflo.au/v1/agents/usage?days=7" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/agents/usage?days=7",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/agents/usage?days=7", {
  headers: { Authorization: `Bearer ${process.env.OMNI_API_KEY}` },
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Response

`200 OK`:

| Field | What it is |
| :--- | :--- |
| `totals` | Tokens (prompt and completion), AI calls and plans over the period, and an `estimated_cost_usd` — null when a model's price isn't known. |
| `days` | Each day, with tokens `by_agent` (keyed by agent id). |
| `agents` | Per agent: tokens and calls over the period, today's tokens against its `daily_limit`, plans made. |
| `pipelines` | Per pipeline agents work: tokens over the period and today, and its `daily_budget`. |
| `models` | Per provider and model: tokens, calls and estimated cost. |
| `uses` | What the tokens were for, per agent, biggest first: planning, workflow AI blocks, knowledge, hand-over summaries and the panel's AI tools. |
| `account` | Today's tokens across every agent, and the account's `daily_budget` (null for none). |

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `module_off` | The account doesn't have AI agents on: they aren't in its plan, or are switched off for it. |
| 403 | `scope_missing` | The key doesn't have the `agents:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
