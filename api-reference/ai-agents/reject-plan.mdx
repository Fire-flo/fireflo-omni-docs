---
title: "POST /v1/agents/plans/{plan_id}/reject"
description: "Reject a plan waiting for approval, and tell the agent why."
---

Rejects a plan waiting for approval — the whole plan, or, in step-by-step mode, a plan with a step waiting. Nothing more of it runs. The agent reads your note the next time it plans for this contact.

<Note>Needs the `agents.plans:write` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `plan_id` | integer | Yes | The plan's id. |

## Body

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `note` | string | No | Why, for the agent. Up to 1,000 characters. |

## Request

<CodeGroup>

```bash cURL
curl -X POST "https://api.fireflo.au/v1/agents/plans/4812/reject" \
  -H "Authorization: Bearer $OMNI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "note": "No discount on inverters this month — offer free installation instead."
  }'
```

```python Python
import os

import requests

response = requests.post(
    "https://api.fireflo.au/v1/agents/plans/4812/reject",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
    json={
        "note": "No discount on inverters this month — offer free installation instead."
    },
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/agents/plans/4812/reject", {

```

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 400 | `invalid_request` | `note` isn't text or is over 1,000 characters (`field` is `note`). |
| 404 | `not_found` | No plan of this account's has that id. |
| 409 | `invalid_state` | The plan isn't waiting for approval. |
| 404 | `module_off` | The account doesn't have AI agents on: they aren't in its plan, or are switched off for it. |
| 403 | `scope_missing` | The key doesn't have the `agents.plans:write` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
