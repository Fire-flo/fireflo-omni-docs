---
title: "GET /v1/agents/{agent_id}"
description: "One AI agent: its setup, status, pipelines and today's figures."
---

One agent, with everything set on it.

<Note>Needs the `agents:read` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `agent_id` | integer | Yes | The agent's id. |

## Request

<CodeGroup>

```bash cURL
curl "https://api.fireflo.au/v1/agents/12" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/agents/12",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/agents/12", {
  headers: { Authorization: `Bearer ${process.env.OMNI_API_KEY}` },
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Response

`200 OK` — the agent. `status` is one of:

| Status | Meaning |
| :--- | :--- |
| `draft` | Being set up, or its key or model changed and it must be verified again. |
| `ready` | Verified, not live yet. |
| `active` | Live: it works contacts. |
| `disabled` | Switched off. |

`provider` is the AI key the agent uses (its label and provider, never the key itself), chosen on the panel. `channels_available` are the channels the account has that an agent can message on, and `channels_missing` those the agent was set up with that the account no longer has. `workflow` sums up its live workflow (null until it has one), `pipelines` are the pipelines it works, and `stats` are today's tokens and plans, the contacts it is working and its plans waiting for approval. `verified_at` is when its key and model were last checked, null when they have changed since. The rest are its settings, as [PATCH /v1/agents/\{agent_id\}](/api-reference/ai-agents/update) changes them.

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No agent of this account's has that id. |
| 404 | `module_off` | The account doesn't have AI agents on: they aren't in its plan, or are switched off for it. |
| 403 | `scope_missing` | The key doesn't have the `agents:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
