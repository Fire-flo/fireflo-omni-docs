---
title: "PUT /v1/agents/{agent_id}/workflow"
description: "Replace an agent's draft workflow, with the revision you read."
---

Replaces the draft with the graph you send. What is live doesn't change until you [publish](/api-reference/ai-agents/publish-workflow).

Send the `revision` you read. If someone saved the workflow since — on the panel or through the API — the save is refused with `revision_conflict`: read it again, apply your change to theirs, and save with the new revision.

<Note>Needs the `agents:write` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `agent_id` | integer | Yes | The agent's id. |

## Body

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `revision` | integer | Yes | The `revision` from your last read or save. |
| `graph` | object | Yes | `nodes` and `wires`, as [GET …/workflow](/api-reference/ai-agents/get-workflow) gives them. `category`, `ai` and `policy` on a node are ignored. |

A graph is refused when:

- it has more than 300 blocks;
- a node's `id` is missing, used twice, or isn't 1 to 40 letters, digits, `-` or `_`;
- a `block` isn't one this agent can use;
- a node's `config` isn't a small object of plain values (up to 30 settings);
- a wire joins nodes or outcomes that aren't there, goes to a Start block or back to its own node, or an outcome has two wires.

Only blocks whose outcomes you choose — **AI decides** and **Send buttons** — keep the `outcomes` you send (up to 12); others always have their block's own. A teammate or knowledge article a block names that isn't in the account is dropped, and the block then shows an issue. A graph can be saved with issues; only publishing needs nothing `broken`.

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 400 | `invalid_request` | `revision` isn't a whole number (`field` is `revision`), or the graph can't be saved (`field` is `graph`; the message says why). |
| 404 | `not_found` | No agent of this account's has that id. |
| 409 | `revision_conflict` | Someone saved the workflow since you read it. |
| 404 | `module_off` | The account doesn't have AI agents on: they aren't in its plan, or are switched off for it. |
| 403 | `scope_missing` | The key doesn't have the `agents:write` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
