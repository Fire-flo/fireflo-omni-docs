---
title: "GET /v1/agents/events"
description: "The agents' activity log, newest first: plans, approvals, actions, AI calls and setup."
---

Everything every agent did, newest first — the panel's **AI agents → Activity**. It is append-only: rows are never changed or removed.

<Note>Needs the `agents:read` scope.</Note>

## Query parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `agent` | integer | No | Only this agent's. |
| `kind` | string | No | Only one kind — for example `plan_created`, `approval_requested`, `approved`, `rejected`, `step_done`, `step_failed`, `llm_call`, `assigned`, `paused`, `guardrail_blocked` or `workflow_published`. |
| `limit` | integer | No | 1 to 100; 50 by default. |
| `starting_after` | string | No | The last id of the previous page — `next` from it. |

## Request

<CodeGroup>

```bash cURL
curl "https://api.fireflo.au/v1/agents/events?agent=7&limit=2" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/agents/events?agent=7&limit=2",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/agents/events?agent=7&limit=2", {
  headers: { Authorization: `Bearer ${process.env.OMNI_API_KEY}` },
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Response

`200 OK` — `has_more` says whether there is another page, and `next` is the `starting_after` for it. Each row has its `kind`, a readable `summary`, the `agent` (and `agent_name`, kept when an agent is renamed or deleted), the `contact` and `plan_id` it was about, the person who did it (`actor`) when a person did, and, for AI calls, the `tokens` used and the `model`. `contact.uuid` is the contact's id everywhere else in the API.

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 400 | `invalid_request` | `limit` is out of range, or `starting_after` isn't an id from this list; `field` names it. |
| 404 | `module_off` | The account doesn't have AI agents on: they aren't in its plan, or are switched off for it. |
| 403 | `scope_missing` | The key doesn't have the `agents:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
