---
title: "GET /v1/agents/plans"
description: "Agents' plans, newest first — the ones waiting for a decision, open ones, or all."
---

Plans the account's agents made, newest first. Use `status=awaiting` for the panel's **Approvals** queue: the plans a person needs to look at.

<Note>Needs the `agents:read` scope.</Note>

## Query parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `status` | string | No | `awaiting` — waiting for approval, whole or a step; or `open` — still has work ahead. All plans when left out. |
| `agent` | integer | No | Only this agent's. |
| `contact` | string | No | Only plans for this contact (their id). |
| `limit` | integer | No | 1 to 100; 50 by default. |
| `starting_after` | string | No | The last id of the previous page — `next` from it. |

## Request

<CodeGroup>

```bash cURL
curl "https://api.fireflo.au/v1/agents/plans?status=awaiting&limit=20" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/agents/plans?status=awaiting&limit=20",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/agents/plans?status=awaiting&limit=20", {
  headers: { Authorization: `Bearer ${process.env.OMNI_API_KEY}` },
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 400 | `invalid_request` | No contact with that id (`field` is `contact`), `limit` out of range, or `starting_after` isn't an id from this list. |
| 404 | `module_off` | The account doesn't have AI agents on: they aren't in its plan, or are switched off for it. |
| 403 | `scope_missing` | The key doesn't have the `agents:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
