---
title: "GET /v1/crm/deals/{deal_id}/timeline"
description: "A deal's story, newest first: its own changes and notes, and what happened with its contact since it began."
---

A deal's story, newest first, as its page shows it: when it was opened and closed, its notes, every change to it, and — when it has a contact — what happened with that contact since the deal began, such as messages on any channel.

<Note>Needs the `crm.deals:read` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `deal_id` | string | Yes | The deal's id. |

## Query parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `limit` | integer | No | 1 to 100; 50 by default. |
| `before` | string | No | `next` from the previous page, for the page before it. URL-encode it: it is a time, with a `+`. |

Each entry has `at`; `kind` — such as `deal` (opened or closed), `note`, `change`, or a message or event of the contact's; `channel` — the channel's key for a message, or empty; `title` and `body` — what happened, in words; and `meta` — details that vary with the kind, such as a note's `author` or a change's `actor`.

## Request

<CodeGroup>

```bash cURL
curl "https://api.fireflo.au/v1/crm/deals/5b2e8c1d-7a4f-4e3b-9c6d-1f0a2b3c4d5e/timeline?limit=3" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 400 | `invalid_request` | `limit` is out of range (`field` is `limit`). |
| 404 | `not_found` | No deal of this account's has that id. |
| 404 | `module_off` | The account doesn't have Pipelines on. |
| 403 | `scope_missing` | The key doesn't have the `crm.deals:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
