---
title: "GET /v1/crm/pipelines"
description: "The account's pipelines, in board order, each with its stages."
---

The account's pipelines, in the order the board shows them, each with its stages in order. Not paged: every pipeline comes back at once.

<Note>Needs the `crm.pipelines:read` scope.</Note>

A pipeline has `id`, `name`, `order` (its place among the account's pipelines), `stages` in order, and `created_at`. A stage has `id`, `name`, `order` and `outcome`: `won` or `lost` for the pipeline's closing stages, empty for the rest.

## Request

<CodeGroup>

```bash cURL
curl "https://api.fireflo.au/v1/crm/pipelines" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/crm/pipelines",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/crm/pipelines", {
  headers: { Authorization: `Bearer ${process.env.OMNI_API_KEY}` },
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `module_off` | The account doesn't have Pipelines on. |
| 403 | `scope_missing` | The key doesn't have the `crm.pipelines:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
