---
title: "PATCH /v1/crm/pipelines/{pipeline_id}"
description: "Rename a pipeline."
---

Renames a pipeline. Its stages and deals are unchanged.

<Note>Needs the `crm.pipelines:write` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `pipeline_id` | integer | Yes | The pipeline's id. |

## Body

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `name` | string | Yes | Its new name. Up to 100 characters, and not a name another of the account's pipelines has. |

## Request

<CodeGroup>

```bash cURL
curl -X PATCH "https://api.fireflo.au/v1/crm/pipelines/3" \
  -H "Authorization: Bearer $OMNI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "name": "Retail sales — South"
}'
```

```python Python
import os

import requests

response = requests.patch(
    "https://api.fireflo.au/v1/crm/pipelines/3",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
    json={
        "name": "Retail sales — South"
    },
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/crm/pipelines/3", {
  method: "PATCH",
  headers: {
    Authorization: `Bearer ${process.env.OMNI_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    "name": "Retail sales — South"
  }),
});
console.log(response.status, await response.json());
```

</CodeGroup>

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 400 | `invalid_request` | `name` is missing, empty, longer than 100 characters, or another pipeline's (`field` is `name`). |
| 404 | `not_found` | No pipeline of this account's has that id. |
| 404 | `module_off` | The account doesn't have Pipelines on. |
| 403 | `scope_missing` | The key doesn't have the `crm.pipelines:write` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
