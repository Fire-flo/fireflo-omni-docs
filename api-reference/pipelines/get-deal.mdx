---
title: "GET /v1/crm/deals/{deal_id}"
description: "One deal: its pipeline, stage, status, value and contact."
---

One deal.

<Note>Needs the `crm.deals:read` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `deal_id` | string | Yes | The deal's id. |

A deal has `id`; `title`; its `pipeline` and `stage` (each an `id` and `name`); `status` — `open`, `won` or `lost`; `value_minor` — its value in the currency's minor unit (paise for `INR`); `currency`; `contact` (`id`, `name`, `phone`, or `null`); `notes` — the deal's own free text; `stage_entered_at` — when it reached its stage; `closed_at` — when it was won or lost, or `null` while open; and `created_at` and `updated_at`.

## Request

<CodeGroup>

```bash cURL
curl "https://api.fireflo.au/v1/crm/deals/5b2e8c1d-7a4f-4e3b-9c6d-1f0a2b3c4d5e" \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://api.fireflo.au/v1/crm/deals/5b2e8c1d-7a4f-4e3b-9c6d-1f0a2b3c4d5e",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch("https://api.fireflo.au/v1/crm/deals/5b2e8c1d-7a4f-4e3b-9c6d-1f0a2b3c4d5e", {
```

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`; `field` is there when one input is at fault.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No deal of this account's has that id. |
| 404 | `module_off` | The account doesn't have Pipelines on. |
| 403 | `scope_missing` | The key doesn't have the `crm.deals:read` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
