---
title: "POST /v1/webhooks/deliveries/{delivery_id}/resend"
description: "Send a delivery again now, as a new delivery with the same event."
---

Sends a delivery's event to its endpoint again, now — for one your server missed or
answered wrongly. It is a new delivery, with its own id and tries; the old one stays as it
was. Find the delivery's id in [GET /v1/webhooks/\{endpoint_id\}/deliveries](/api-reference/webhooks/deliveries).

<Note>Needs the `webhooks:write` scope.</Note>

## Path parameters

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `delivery_id` | string | Yes | The delivery to send again. |

## Request

<CodeGroup>

```bash cURL
curl -X POST https://api.fireflo.au/v1/webhooks/deliveries/e9a1c3b5-7d2f-4e6a-8b0c-1f3d5e7a9c24/resend \
  -H "Authorization: Bearer $OMNI_API_KEY"
```

```python Python
import os

import requests

response = requests.post(
    "https://api.fireflo.au/v1/webhooks/deliveries/e9a1c3b5-7d2f-4e6a-8b0c-1f3d5e7a9c24/resend",
    headers={"Authorization": f"Bearer {os.environ['OMNI_API_KEY']}"},
)
print(response.status_code, response.json())
```

```javascript Node
const response = await fetch(
  "https://api.fireflo.au/v1/webhooks/deliveries/e9a1c3b5-7d2f-4e6a-8b0c-1f3d5e7a9c24/resend",
  {
    method: "POST",

      Authorization: `Bearer ${process.env.OMNI_API_KEY}`,

```

</CodeGroup>

## Errors

Every refusal is `{"error": {"code", "message", "field"}}`.

| Status | Error code | When |
| :--- | :--- | :--- |
| 404 | `not_found` | No delivery of this account's has that id. |
| 403 | `scope_missing` | The key doesn't have the `webhooks:write` scope. |

Any request can also be refused for its key, its account or its rate (`key_required`, `invalid_key`, `account_suspended`, `plan_excludes_api`, `address_not_allowed`, `rate_limited`); see [the overview](/api-reference/overview).
